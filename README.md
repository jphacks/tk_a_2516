## 製品概要
### 背景(製品開発のきっかけ、課題等）
グローバル化が進む現代社会において、英語スピーキングの能力は非常に重要である。スピーキングは当然声を出すものであるから、家の外では練習できない。しかし、忙しい現代人は電車での移動時間しか勉強時間を確保できなかったり、日中の頑張りに燃え尽きて家の環境では勉強をする気が起きなかったりして、英語を話すことを諦めがちである。

私たちはこの課題を解決するサービスを開発しました。

### 製品説明（具体的な製品の説明）
本製品は英語学習のためのスマホ用Webアプリです。
始めに例文が表示されます。録画開始ボタンを押し、5秒経過するか録画停止ボタンを押すまで口の動きの読み取りを実行します。読み取ったものを文字起こしし元の例文と比較・採点しすることで、あなたの英語の発音が正しいかどうかを判定します。

### 特長
#### 1. 特長1：声を発さず口を動かすだけで、カメラが口の動きを認識して正しく発音できているか判定してくれます。
#### 2. 特長2：非常に簡素なUIにより直感的に操作することができるため、誰でも簡単に利用できます。
#### 3. 特長3：LLMを用いた読み取りにより、精度の高い判定が可能です。

### 解決出来ること
* 声を発することができない環境での英語の発音練習が可能になり、いつでもどこでもスピーキングの練習が可能になります。
* 電車での移動時間など、隙間時間を英語学習の時間として有効活用できるようになります。
* 英語に触れる時間が多くなることで英語学習の挫折率を下げ、多くの人々に自己成長の機会を提供することができます。

### 今後の展望
### 注力したこと（こだわり等）
* Lip reading機能を提供するChaplinというOSSを利用するにあたって、Chaplinはもともとそれ自体がwebアプリの形で提供されており、
ReactフロントエンドからLip reading機能呼び出すことができませんでした。そこでChaplinのコードを改良し、FastAPIサーバーとして実装しなおす形でバックエンドを作成しました。
* 採点時に正解の文とユーザーの回答を比較するためのアルゴリズムを工夫し、
連続するマッチ数が最大となるような選び方で採点を行うようにしています。
これにより、例えば、正答が`Hello, how are you doing?`でありユーザーの回答が`how are you?`であった際に、中央の3単語がマッチしていると見なされ、`how`, `are`, `you`の3単語が正解となります。
