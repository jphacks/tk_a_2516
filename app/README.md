# 英語発音チェッカー - フロントエンド

口の動きだけで英語の発音を判定するスマホ用Webアプリのフロントエンド部分です。

## 🎯 アプリの特徴

- **電車の中でも練習可能**: 音声なしで口の動きのみで発音判定
- **90秒で伝わる課題解決**: 英会話学習者の「家ではだらける」「外では練習できない」問題を解決
- **MVP設計**: 本質的な機能のみに集中した最小実用版

## 🚀 セットアップ

```bash
cd frontend
npm install
npm run dev
```

ブラウザで `http://localhost:3000` にアクセス

## 📱 主な機能

1. **例文表示**: 練習する英文を表示
2. **映像録画**: フロントカメラで口の動きを5秒間録画
3. **採点結果表示**: 発音の評価とフィードバックを表示
4. **進捗管理**: 複数の例文を順次練習

## 🛠 技術スタック

- React 18 + TypeScript
- Tailwind CSS
- Vite
- WebRTC (MediaRecorder API)

## 🎨 デザインの特徴

- **モバイルファースト**: スマホでの使用を前提としたUI
- **直感的な操作**: ワンタップで録画開始
- **視覚的フィードバック**: 録画中・処理中の状態を明確に表示
- **段階的な評価**: スコアに応じた詳細なフィードバック

## 🔧 開発メモ

- バックエンドAPIとの連携部分はモック実装
- 実際の口の動き解析はバックエンド側で実装予定
- カメラアクセス許可の適切なエラーハンドリング
- スマホでのタッチ操作に最適化
